## 🚀 Projeto em Destaque

### 🎮 HistoSaga — App Educacional (TCC • 2025)
🔗 https://github.com/soaresravi/tcc-histosaga/

Aplicativo mobile gamificado para ensino de História, desenvolvido com **React Native**, **TypeScript** e **Firebase**, focado em engajamento, progressão personalizada e experiência do usuário.

**Principais funcionalidades:**
- 🔐 Autenticação de usuários com Firebase Auth  
- 🗄️ Banco de dados NoSQL com Firestore  
- 🔄 Sincronização automática offline/online  
- 🎮 Sistema de gamificação (XP, níveis, progressão)  
- 📱 Interface interativa com animações e feedback visual
